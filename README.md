# 图片识别自动点击：自定义流程

## 使用方法

1. 准备好需要识别的图片，建议在目标电脑上截取清晰、独特的按钮区域并保存为 PNG。
2. 打开程序，点击「添加图片点击」选择图片；点击「添加等待」输入等待秒数。新步骤会插入到选中步骤之后；未选中时添加到末尾。
3. 选中步骤后可修改、删除、上移或下移。双击步骤也可以修改。同一张图片可以在流程中出现多次。
4. 设置启动等待（默认 10 秒）、每步图片识别超时、相似度；按需勾选循环执行。点击「保存配置」可单独保存，也可以点击「保存并开始」。
5. 执行期间点击「停止」可中止等待或识别，也可以将鼠标移至屏幕角落紧急停止。

示例：图片 A → 等待 2 秒 → 图片 B → 等待 1 秒 → 图片 B。步骤按列表从上到下执行；流程结束后若选择循环，则从第一步开始下一轮。配置会保存在当前用户的 `%APPDATA%\\ImageClickerWin7\\config.json`；首次运行新版会读取旧版两张图片的设置并转换为步骤。若移动了图片文件，请在程序中重新选择。

相似度默认 0.90，降低可以容忍更多像素差异，但过低可能匹配到其他区域。识别超时设为 0 表示一直等待。目标需要出现在主屏幕上，截图时和使用时的窗口大小、缩放比例应尽量一致。

## 打包

仓库的 GitHub Actions 使用 32 位 Python 3.8.10 和固定依赖构建 Windows EXE。推送后打开 Actions，下载构建产物 `ImageClickerWin7-x86`。也可在 Windows 7 机器安装 32 位 Python 3.8.10 后运行 `py -3.8-32 -m pip install -r requirements.txt` 和 `py -3.8-32 -m PyInstaller --noconfirm --clean --onefile --windowed --name ImageClickerWin7 app.py`。

GitHub 构建机上的测试不等同于 Windows 7 实机测试；实际兼容性以目标电脑为准。
